# Ninja Cafe Axel

Ninja Luxe Café Pro Seri için Türkçe mobil web uygulaması.

## Özellikler

- **Ana Sayfa** — Logo, hızlı erişim ve iki ana bölüme giriş
- **Pro Series** — Makinenizi tanıyın, Barista Assist™, demleme rehberleri, temizlik & bakım
- **Kahve Tarifleri** — 16 tarif: espresso, filtre, soğuk ve diğer kategoriler; arama + filtreleme
- Mobil öncelikli (iOS ve Android)
- PWA hazır (ana ekrana eklenebilir)
- Renk paleti: koyu arka plan + altın vurgular

## Kurulum

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Teknoloji

- React + Vite
- CSS değişkenleri (CSS custom properties)
- PWA manifest
- Google Fonts: Playfair Display + Inter
